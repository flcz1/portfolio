# Abdullah Alzabry | Portfolio

A personal cybersecurity portfolio website showcasing my security projects, technical skills, certifications, and professional background.

**Live site:** [https://portfolio-flcz1.vercel.app](https://github.com/flcz1/portfolio)

## Features
- Home page with hero, featured security projects, skills, about, and contact sections
- Smooth scrolling navigation across all sections
- Responsive dark-mode cyber design for mobile, tablet, and desktop
- Clean layout inspired by modern developer portfolios

## Tech Stack
- HTML5
- Tailwind CSS
- JavaScript (ES6)
- FontAwesome Icons
